Design Specifications (VerCore)

Pipeline: 5-stage, in-order, single-issue.

Exclusions: DO NOT support compressed instructions.

Hardware Interfaces (Synchronous to master clk):

Instruction cache interface (32-bit datapath).

Data cache interface (32-bit datapath).

Physical Design Constraints: Valid input 70% into clock cycle, Valid output 20% into clock cycle.

Task 1: Microarchitecture Specification
Before writing RTL, document the microarchitecture plan in design_journal.md:

Pipeline Stages: Define operations for IF, ID, EX, MEM, WB.

Hazard Unit: Explain data hazard forwarding and control hazard flushing. Load-Use hazards must stall the pipeline.

ZMMUL Extension: Describe the multiplier implementation. Prioritize structural correctness over single-cycle speed to aid timing closure.

Memory & MMIO Strategy: The core will NOT include an internal cache. It will expose an Instruction Memory Interface and a Data Memory Interface. MMIO is memory-mapped and shares the Data Memory Interface. Address decoding for MMIO happens outside the core.

Interface Definitions:

Instruction Interface: icache_req (out), icache_addr (out, 32-bit), icache_rdata (in, 32-bit), icache_valid (in).

Data Interface: dcache_req (out), dcache_we (out), dcache_size (out, 2-bit for byte/half/word), dcache_addr (out, 32-bit), dcache_wdata (out, 32-bit), dcache_rdata (in, 32-bit), dcache_ready (in).
